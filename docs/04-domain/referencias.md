# Referencias ISO

**Fase:** 2 · **Estado:** Aceptado

Catálogos globales de solo lectura:

- País: código ISO y nombre legible.
- Moneda: código ISO, nombre, símbolo y cantidad de decimales.

La API solo permite listar y consultar; no crea, edita ni elimina referencias.
Talleres valida códigos mediante un contrato público. No se exige que la
Moneda corresponda al País. Las Órdenes copian el snapshot monetario necesario
y no dependen de que la referencia cambie.

Trazabilidad: BR-022/023/025; RF-REF-001; AC-024/025.
