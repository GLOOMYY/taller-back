# Pruebas de API

## Estado

**Aceptadas** para los contratos de fases 1 y 2.

Cubrirán validación, serialización, autenticación, autorización, errores seguros, idempotencia/concurrencia acordada, paginación/filtros y compatibilidad. Cada recurso tenant-scoped tendrá escenarios del Taller autorizado, otro Taller y referencias cruzadas.

Fase 2 cubre además importes como strings, catálogos inactivos, estados,
garantía, stock/Pagos y filtrado público. OpenAPI debe contener exactamente las
rutas aceptadas. Las pruebas de API no sustituyen dominio o repositorio.
