# Nombres de recursos

## Propuesta

- Mantener vocabulario de dominio en español y nombres consistentes.
- Preferir sustantivos para recursos y acciones solo cuando no encajen naturalmente en semántica del protocolo.
- No exponer nombres de colecciones o clases de infraestructura.
- Evitar abreviaturas no incluidas en el glosario.

Para fase 1 se aceptan sustantivos plurales en español, campos `snake_case` y
recursos tenant anidados bajo `/talleres/{taller_id}` según el contrato publicado.
