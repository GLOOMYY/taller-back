# Filtrado y ordenamiento

## Propuesta

- Permitir solo campos y operadores explícitamente listados por recurso.
- Validar tipos, rangos y combinaciones.
- Aplicar siempre el scope tenant antes o junto con filtros del usuario.
- Alinear filtros frecuentes con índices justificados.
- Definir un orden determinista para paginación.
- Rechazar campos desconocidos en vez de ignorarlos silenciosamente cuando el contrato lo establezca.

Filtros, búsquedas de texto y ordenamientos concretos están **Pendientes**.
